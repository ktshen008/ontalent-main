**Important:** this is a generated site — make every change at the **source** (`build.py`, its templates, or content files) and rebuild, so the change survives regeneration. Do not hand-edit only the generated HTML. Work on a branch and preview before merge.

## 1) Remove `noindex, nofollow` site-wide — launch blocker
- Every page currently emits `<meta name="robots" content="noindex, nofollow">`. Find where it's set (most likely the shared `<head>` template in `build.py` or a base partial) and remove it, so generated pages no longer carry it. Rebuild and confirm it's gone from `index.html`, `pathways-robotics.html`, and `team-support.html`.
- Check for a `robots.txt` that blocks crawling; if one exists and disallows, update it to allow (`User-agent: *` / `Allow: /`). Optional but nice: generate a `sitemap.xml` and reference it in `robots.txt`.

## 2) Remove the preview banner

Find and remove that markup wherever it's emitted (search the source for `preview version` / `community review`). If it sits behind a build flag, turn the flag off and remove the element. Rebuild and confirm it's gone.

## 3) Point everything at ontalent.org (og:image + CNAME)
